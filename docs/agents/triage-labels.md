# Triage 標籤

工程技能使用五種標準 triage 角色。本表將角色對應至本儲存庫 issue tracker 使用的標籤字串。

| Matt Pocock 技能中的角色 | 本儲存庫的標籤 | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 維護者需要評估此 issue |
| `needs-info` | `needs-info` | 等待回報者提供更多資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交由非同步代理處理 |
| `ready-for-human` | `ready-for-human` | 需要由人類實作 |
| `wontfix` | `wontfix` | 不會採取行動 |

技能提及某個角色時（例如「套用可交由代理處理的 triage 標籤」），請使用表格中對應的標籤字串。

若 issue tracker 的標籤用語變更，請更新「本儲存庫的標籤」欄。
